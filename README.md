# 창업노트

사업자 정보를 바탕으로 공공 지원사업의 조건을 대조하고, 원본 신청서의 초안 작성·검토·저장을 돕는 서비스입니다.

## 시연과 팀 공유 자료

- [종합 기능 시연 시나리오 · HTML](docs/demos/2026-10-01-afternoon-demo/index.html): 로그인 정보·복사 버튼, 약 7분의 10단계 액션 안내·발표 멘트, 한 단계씩 보기와 예비 화면을 담은 담당자용 진행 문서. 2026-10-01 실제 인수 기록을 기준으로 합니다.
- [창업노트 6개월 회고 · 발표용 HTML](docs/presentations/2026-10-01-six-month-review/slides.html): 22장 발표 덱. [PowerPoint](docs/presentations/2026-10-01-six-month-review/review.pptx) · [PDF](docs/presentations/2026-10-01-six-month-review/slides.pdf)
- [6개월 전체 기록](docs/presentations/2026-10-01-six-month-review/history.html) · [회고 자료 안내·출처](docs/presentations/2026-10-01-six-month-review/README.md)

HTML 문서는 서버 없이 로컬 브라우저에서 열 수 있습니다. 회고 덱의 기록 기준은 2026-10-01 09:26 KST로, 같은 날 오후의 최종 시연 결과와 시점이 다릅니다. 시연 HTML에는 담당자가 바로 로그인할 수 있도록 시연 계정의 비밀번호를 표시합니다. 발표 화면 공유 전 로그인하고 가이드는 담당자 화면에 두세요.

## 발표 담당자 빠른 시작

1. 저장소를 내려받고 [시연 가이드](docs/demos/2026-10-01-afternoon-demo/index.html)를 브라우저로 엽니다. 이미지와 예비 파일을 함께 쓰므로 HTML이 들어 있는 폴더 구조를 유지하세요.
2. 가이드 상단의 이메일·비밀번호를 복사해 로그인하고, 저장된 작성 화면과 예비 HWPX를 미리 엽니다.
3. 서비스 창을 공유하고 가이드의 **한 단계씩 보기**를 누릅니다. **← →**로 이동하며 행동·확인 결과·발표 멘트를 따라갑니다. **Esc**는 전체 순서로 돌아갑니다.
4. 약 7분 동안 10단계를 진행합니다. 시간이 부족하면 **02 조건 → 07 문안 → 10 다시 열기**, 화면이 지연되면 각 단계의 예비 자료로 이어갑니다.

GitHub 파일 화면에서는 HTML이 실행되지 않습니다. 내려받은 파일을 로컬 브라우저에서 여세요. 시연 가이드의 현재 운영 로그인과 PDF 외관은 별도 검증이 남아 있습니다.
