## 주의/함정 (이번 세션 실측)

- **`claude --bare` 금지** — OAuth를 안 읽고 API 키 과금으로 전환됨. shim 고정 플래그는 `--safe-mode`(사용자 스코프 CLAUDE.md 차단 + OAuth 유지, 실측 확정).
- **윈도 소진 기록**: batch의 `[CLAUDE_CLI_WINDOW_EXHAUSTED]`는 불변 실패 증거로 보존한다. 현재는 리셋 뒤 같은 명령을 재실행하지 않으며 Gate R 이후 별도 experiment로만 다룬다.
- **A/B 부산물 런 주의**: spike-out의 v5 런 23건은 과거 `lab:ai-review` 기본 대상 풀에 자동 편입되던 위험 증거다. 현재는 검수 배치를 시작하지 않으며, 향후에도 exact receipt-bound target만 사용한다.
- **CLI 명목 비용은 근사치**: 입력은 cache_creation 합산 보정으로 회복했지만 출력에 추론 토큰이 포함돼 API 대비 과대(보수적 방향). 현재 costUsd는 fan-out·모델·문서 복잡도 telemetry일 뿐이며 구독 실행·품질 게이트가 아니다.
- **딥분석 재실행은 비결정적** — essence 집합 완전 일치 기준의 축 일치율은 동일 모델 재실행 쌍도 16.7%(실측). 레인 품질 비교는 반드시 원문 대조 판정으로 할 것(수치 일치율로 판정하면 오판).
- **병렬 세션 변경 불가침**: 워킹트리의 apply-workspace·application-roundtrip·routePolicy·applyReconciledFields·package.json(`test:apply-workspace` hunk)은 다른 세션 소유. `git add -A` 금지, 명시 스테이징만.
