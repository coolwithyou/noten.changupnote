## 주의/함정 (이번 세션 실측)

- **`claude --bare` 금지** — OAuth를 안 읽고 API 키 과금으로 전환됨. shim 고정 플래그는 `--safe-mode`(사용자 스코프 CLAUDE.md 차단 + OAuth 유지, 실측 확정).
- **윈도 소진 시**: batch가 `[CLAUDE_CLI_WINDOW_EXHAUSTED]` 마커를 감지해 신규 착수를 스스로 중단. 리셋 후 같은 명령 재실행 — 단 소진 시점에 이미 착수됐던 소수 error 런만 `--retry-errors` 필요(이 플래그는 무관한 실패 런도 재실행하니 남발 금지).
- **A/B 부산물 런 주의**: spike-out에 v5 신규 런 23건(API 10·CLI 9·sonnet 4)이 쌓임. `lab:ai-review` 기본 모드는 "사람 검수 없는 ok 런"을 대상으로 잡으므로 **다음 검수 배치에서 이들이 대상 풀에 들어가 fable-5 API 비용 발생** — 의도 확인 후 `--grant-ids`로 좁히거나 수용할 것.
- **CLI 명목 비용은 근사치**: 입력은 cache_creation 합산 보정으로 회복했지만 출력에 추론 토큰이 포함돼 API 대비 과대(보수적 방향). costUsd는 게이트 잣대일 뿐 실지출 0.
- **딥분석 재실행은 비결정적** — essence 집합 완전 일치 기준의 축 일치율은 동일 모델 재실행 쌍도 16.7%(실측). 레인 품질 비교는 반드시 원문 대조 판정으로 할 것(수치 일치율로 판정하면 오판).
- **병렬 세션 변경 불가침**: 워킹트리의 apply-workspace·application-roundtrip·routePolicy·applyReconciledFields·package.json(`test:apply-workspace` hunk)은 다른 세션 소유. `git add -A` 금지, 명시 스테이징만.
- 검수 가이드(`docs/research/2026-07-18-공모딥분석-검수판정-가이드.md`)를 수정하면 이후 ai-review/audit 프롬프트가 바뀜(§0·1·2·5가 rubric으로 주입됨) — guideSha256은 기록용일 뿐 차단 없음.
