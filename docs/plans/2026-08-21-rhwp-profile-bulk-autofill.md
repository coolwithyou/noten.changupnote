# RHWP 등록정보 일괄 입력 계획

- 작성일: 2026-08-21
- 상태: 구현 중
- 범위: 프로덕션 신청서 작업공간의 개인·회사 등록정보 저장과 열린 HWP/HWPX 문서 일괄 입력
- 제품 정본: `docs/plans/2026-08-19-field-aware-document-editor-agent.md`

## 1. 목표

사용자가 저장한 개인·회사 정보를 현재 열려 있는 RHWP 신청서의 **확정된 입력 칸**에 한 번에 채운다. 저장된 정보가 부족하면 일괄 입력 대화상자에서 보완할 수 있고, 보완한 값은 문서에만 머물지 않고 이후 신청서에서도 재사용하는 등록정보로 저장한다.

초기 지원 항목은 다음과 같다.

- 개인: 성명, 신청용 이메일, 휴대전화, 주소, 우편번호
- 회사: 회사명, 대표자명, 사업자등록번호, 회사 이메일, 회사 전화번호, 사업장 주소, 우편번호

주민등록번호, 서명·직인, 동의 여부, 계좌·인증 정보는 일괄 입력 대상에서 제외한다.

## 2. 제품 계약

1. **열린 문서에 적용한다.** 다음 진입 때 원본을 미리 채우는 방식은 이 기능의 성공으로 보지 않는다.
2. **사용자 승인 전 문서 변경은 0건이다.** 대화상자에서 저장·입력 대상을 확인한 뒤 한 번의 명시적 실행으로만 변경한다.
3. **필드 라벨을 쓰기 주소로 사용하지 않는다.** `fieldId`와 현재 문서에서 유일하게 확인된 Studio target만 쓴다.
4. **추정하지 않는다.** 위치 미확인·중복 위치·제3자 정보·민감정보·의미 불명확 필드는 제외하고 이유를 보여준다.
5. **기본은 빈 칸만 채운다.** 현재 값이 있는 필드는 덮어쓰지 않는다. 이후 별도 덮어쓰기 UX가 필요하면 독립 승인을 설계한다.
6. **프로필 저장과 문서 입력을 분리해 복구한다.** 프로필 저장 성공 뒤 문서 적용이 실패하면 저장된 프로필은 유지하고, 문서 변경은 전부 원상 복구하거나 편집을 잠근다.
7. **문서 preimage를 재검증한다.** 문서 SHA, 필드 기존 값·서식·인접 문맥을 각 적용 직전에 확인한다. 하나라도 달라지면 남은 입력을 중단한다.
8. **사업자번호 검증 상태를 보존한다.** 사용자가 직접 입력한 번호는 형식·체크섬을 검증해 저장하되 `verified=false`로 둔다. 이미 검증된 번호와 다른 값은 자동 변경하지 않는다.

## 3. 데이터 정본

인증·매칭·신청서 입력의 의미를 섞지 않는다.

- `users.email`: 로그인·인증 이메일로 유지
- `company_profiles`: 지원사업 매칭 조건으로 유지
- `user_application_profiles`: 신청서용 개인 연락처·주소
- `company_application_profiles`: 신청서용 회사 연락처·주소·대표자
- `companies.name`, `companies.biz_no`: 회사 법적 기본정보 정본

프로필 API는 선택된 회사에 쓰기 권한이 있는 사용자만 사용할 수 있다. 개인 프로필은 본인 행만, 회사 프로필은 현재 회사 행만 읽고 쓴다.

## 4. 모듈 경계

### 프로필 저장 모듈

`applicationAutofillProfile`은 읽기·정규화·검증·저장을 한 인터페이스로 감춘다. HTTP route와 UI는 DB 테이블을 직접 알지 않는다.

### 일괄 입력 계획 모듈

`applicationProfileAutofill`은 다음 입력만 받는다.

- 연결 필드의 `fieldId`, `fieldKey`, `mappedCompanyField`, label
- 등록정보 값
- 현재 Studio binding 상태와 현재 값

출력은 `ready | missing_profile | already_filled | blocked` 항목 목록이다. UI와 RHWP 쓰기 모듈은 동일 계획을 공유한다.

### RHWP 적용 모듈

Studio surface는 `applyProfileAutofill(entries)`만 노출한다. 내부에서 각 필드의 exact binding을 다시 수집하고 순차 적용·역순 복구·최종 snapshot 저장을 담당한다.

## 6. 완료 조건

- 사용자가 누락된 이름·전화·이메일·회사명·대표자명·사업자번호·주소를 대화상자에서 입력하고 저장할 수 있다.
- 새로고침 뒤 동일 등록정보가 복원된다.
- 현재 열린 문서에서 확정된 빈 입력 칸만 미리보기 목록에 포함된다.
- 승인 후 값이 검은색 실제 입력 스타일로 들어가며 placeholder가 남지 않는다.
- 값이 있거나 위치가 불명확한 필드는 변경되지 않는다.
- 적용 중 실패한 경우 전부 복구되거나 편집이 잠기며 부분 성공을 완료로 보고하지 않는다.
- 저장한 문서를 다시 열어도 입력값과 서식이 유지된다.

## 7. 이번 구현의 증거 경계

단위·렌더·타입 검증은 데이터 계약과 UI 연결을 증명한다. 실제 HWP/HWPX roundtrip 증거를 확보하기 전에는 문서 적용 전체를 완료로 선언하지 않는다.
