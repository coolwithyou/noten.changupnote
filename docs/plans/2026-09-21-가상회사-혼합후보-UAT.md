# 가상회사 verified·discovery 혼합 후보 UAT

작성일: 2026-09-21 KST

## 목적

현재 Production 실행 코드와 같은 기준 소스에서, 외부 사업자 조회와 운영 데이터 쓰기 없이
`verified`와 `discovery` 후보가 한 회사 결과에 함께 노출되는지 확인한다.

가상 회사 저장, 랜딩 품질 관측 저장도 수행하지 않는다.

## 단일 UAT

1. 가상 사업자번호로 회사 미리보기에 진입한다.
2. 매칭 결과에 `verified`와 `discovery`가 모두 존재하는지 확인한다.
3. discovery가 자격 충족이나 점수로 단정되지 않고 공식 원문 확인 행동을 제공하는지 확인한다.
4. verified의 기존 근거·판정이 discovery 활성화 때문에 사라지지 않는지 확인한다.
5. 목록 추가 로딩 1회에서 중복이 없는지 확인한다.

PASS는 두 근거 수준의 동시 존재, discovery 안전 projection, verified 보존, 원문 CTA,
중복 0을 모두 충족하는 경우다. 비공개·마감 공고 노출, discovery의 적격 확정,
verified의 체계적 소실, 반복 5xx, 운영 관측 저장은 STOP이다.

실제 사용자 인증·저장 회사·권한 경로는 이 가상회사 UAT의 증거 범위가 아니다.
