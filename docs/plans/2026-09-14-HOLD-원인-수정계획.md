# 동일 3건 재측정 HOLD 원인 수정

사용자 승인: 재측정에서 확인한 문제의 다음 수정 단계 진행.
기준 소스: `2659788`. 구현은 sol-xhigh가 한 범위씩 수행하고 총괄이 통합·검증한다.
의미가 불명확한 계약은 gpt-6-astra high의 독립 자문과 원문 대조로 결정한다.

## 딥분석

1. 서약 속 사실과 현재 신청 제외 효과를 구분한다. 중복지원·IP 부존재 서약 자체나
   사후 환수만으로 exclusion을 생성하지 않는다. 같은 사실에 결속된 명시적 제외효과는 보존한다.
2. 영어 발표의 진행방식과 영어능력의 명시적 평가·배점을 구분한다. 정상적인 소통능력·
   글로벌 진출 준비도·성장 가능성 평가를 삭제하지 않는다.
3. 원문 인용 결속 후에만 제한적 의미 검증을 적용한다. 불일치는 targeted repair로 보내며
   모델 설명을 원문의 효과 증거로 사용하거나 무관한 다른 절의 제외 문구로 통과시키지 않는다.
4. 안성의 `evaluation_precision` 범위 자기모순도 분리 수정한다. 정상 자격 한계의 보존은 유지한다.

## RHWP: 재측정 보고서의 좌표 해석 보완

기존 보고서의 ‘라벨 셀 오추천 2개’는 parsed 좌표만 대조한 잠정 판단이었다.
수정 전 실제 `@rhwp/core` WASM과 같은 HWPX SHA로 제품 필드 변환·anchor resolver를
실행해 실제 쓰기 target을 추가 확인했다. 글리프 폭은 근사했으므로 시각 UAT가 아니라
원본 문서의 구조적 cell identity 검증이다.

- `법인등록번호` 라벨 후보는 정상적으로 오른쪽 `해당 시` 값 셀(row5,col4)을 가리킨다.
  이 정상적인 라벨 기반 필드를 제거하면 안 된다.
- 별도 `해당 시` 후보는 베트남 법인/지사 여부 라벨(row4,col7)을 쓰기 대상으로 잘못 고른다.
  입력란 안의 placeholder를 별도 라벨로 해석하는 중복 후보·연결 계약을 보완한다.
- `이미지` 후보는 라벨 자체가 아니라 우측의 nested image host(row11,col2)를 가리킨다.
  이를 일반 textarea로 제공하는 것이 현재 쓰기 계약에서 지원되는지 검증하고, 지원 근거가
  없으면 이미지 입력 기능을 추정하지 않고 지원되지 않는 구조로 명시한다.

라벨을 일괄 차단하지 않는다. 정상 label→value 필드·같은 셀 placeholder·장문 안내문·
공동대표 등 복구된 입력을 보존하고 실제 target의 역할·중복·지원 범위를 검증한다.
반복 저신뢰 입력을 사용자 확인으로 보존하는 경로도 구조 검증을 우회할 수 없어야 한다.

## 검증

재측정의 실제 원문·응답을 회귀 증거로 사용한다. 잘못된 exclusion/평가 효과와 정상 명시
효과, 병합 셀의 라벨·값 관계, 정상 입력 유지, unsupported media의 정직한 상태를 검증한다.
관련 suite와 공유 계약 gate를 통과시킨 뒤 현재 제공 결과의 읽기 호환성을 확인한다.
기존 불변 receipt는 수정하지 않고 변경 코드의 증거를 별도로 남긴다.

코드 검증, live 재분석 품질, 실제 시간, native 편집·저장·재열기, 서비스 배포는 각각
확인한 범위만 보고한다. 과거 HOLD 결과를 자동 승격하거나 운영 유료 분석을 활성화하지 않는다.

로컬 조사 증거: `spike-out/hold-fixes-20260914/native-targets-before.json`.
