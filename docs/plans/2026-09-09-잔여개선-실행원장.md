- 전체 목록의 구현·테스트·환경 구성·배포 작업을 진행하되, 새 live 모델 실행은 현행
  AGENTS의 exact manifest 승인 후 grant 계약을 유지한다. 미승인 모델 호출은 하지 않는다.
- 분석 자산의 실제 승격은 조사로 exact 대상과 현재 material binding을 확정한 뒤 승인 범위를
  대조한다. 과거 승인이나 이번 일반 개선 요청만으로 임의 cohort를 추가하지 않는다.
- 운영 worker `observe_only`를 유지한다. Cloudflare 접근 정책을 임의로 완화하지 않는다.
- 장기 개발 서버는 시작하지 않는다. 기존 실행 포트를 먼저 확인하고, 허용된 격리 인수 도구의
  유한 production 인수와 개발 서버를 구분한다.
- 코드/자동 테스트/격리 실제 인수/외부 계정 인수/DB 적용/배포를 각각 기록한다.
- 테스트용 로그인 성공을 실제 이메일 소유권이나 외부 OAuth 성공으로 보고하지 않는다.
