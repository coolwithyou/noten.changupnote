이 HTTP 스모크는 인증된 사용자의 RHWP 편집·저장·재열기 UAT나 live LLM 품질 검증을
대체하지 않는다. 운영 API 인증 경계와 배포 가용성, 기존 데이터 읽기 호환성까지 확인했다.

GCP는 전용 configuration의 base 계정 재인증이 만료되어 token preflight가 실패했다.
세 Cloud Run Job은 이 작업에서 조회·갱신·실행하지 못했다. 사용자에게 다음 재로그인을
요청한 상태이며 별도 계정이나 서비스 계정 key로 우회하지 않았다.

```sh
gcloud auth login sw@noten.im --configuration=cunote-codex-dev
```

Cloud Run 이미지 반영은 미완료다. 운영 유료 분석 활성화, Scheduler 변경,
보류된 분석 결과의 `lab:promote --write`는 실행하지 않았다.

증거 디렉터리: `spike-out/finding-fixes-20260914/`와 `spike-out/improvement-20260914/`.
`verification.json`에 집계 검증의 소스 tree·종료 코드·로그 해시,
`release-source.json`에 배포 archive·파일별 manifest 해시를 보존했다.
원문·DB 행·로컬 실행 로그는 비공개 로컬 증거로 유지한다.
