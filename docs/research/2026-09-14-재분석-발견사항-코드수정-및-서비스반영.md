### GCP 후속 반영

최초 시도는 base 계정 인증 만료로 중단됐으나, 사용자 재로그인 후 2026-09-14 15:17 KST에
tokeninfo의 실제 호출 주체가 전용 impersonation 서비스 계정임을 다시 검증했다.
`cunote-codex-dev` configuration으로 웹과 동일한 `0034d36` archive를 빌드했다.

- Cloud Build: `cde87e44-a00a-43e8-9241-b40e03d9c8d1`, SUCCESS.
- staging: `gs://changupnote-com_cloudbuild/cunote-codex-dev/source`.
- 이미지: `asia-northeast3-docker.pkg.dev/changupnote-com/cunote/deep-analysis-worker`
  digest `sha256:07942215001f5097b59a093142bdd2f89ae3bc460543945094863046a60631d3`.
- 태그 대신 빌드 결과의 digest로 세 Job을 갱신하고 `GIT_COMMIT_SHA`를 위 exact 소스로 설정했다.

| Job | generation 전 → 후 | 배포 상태 |
| --- | --- | --- |
| cunote-deep-analysis | 100 → 101 | Ready, observe_only 유지 |
| cunote-deep-analysis-input-preparation | 36 → 37 | Ready |
| cunote-deep-analysis-serving-monitor | 29 → 30 | Ready |

배포 직전 generation과 spec drift를 검사했다. 배포 후 image·GIT_COMMIT_SHA와 CLI 생성
metadata인 nonce·client version을 제외한 전체 spec이 동일하다. 서비스 계정, command/args,
리소스, timeout/retry, 환경변수와 secret 참조가 보존됐으며 비교 파일은 literal 환경값 대신
SHA-256을 기록한다.

Scheduler의 상태·주기·시간대·대상도 동일하다. 메인과 입력 준비는 PAUSED,
serving monitor는 ENABLED다.

메인 관측 스모크 `cunote-deep-analysis-fldsz`는 15:25:54 KST에 성공 종료했다.
Cloud Run의 Completed=True·succeededCount=1과 DB heartbeat를 함께 확인했다.
heartbeat의 serviceRevision은 위 exact 소스이며 `status=idle`, `executionMode=observe_only`,
`claimed=0`, `enqueueSkipped=true`, `analysisSkipped=true`, `budgetMutationSkipped=true`다.
DB runtime은 전후 모두 `paused`, generation 403, owner/expiry 없음, 활성 deep/application
lease 0건으로 동일했다. heartbeat 1행이 기록됐으며 모델 분석은 착수하지 않았다.

입력 준비·serving monitor의 별도 수동 실행은 하지 않았다. 두 Job은 빌드·배포 Ready와
실행 계약 보존을 확인했고 기존 Scheduler 상태를 유지했다. 실제 분석 품질·소요시간 및
인증된 편집 UAT는 앞서 구분한 미검증 범위로 남는다.

이 배포는 운영 유료 분석 활성화나 보류된 분석 결과의 `lab:promote --write`를 수행하지 않는다.
사용한 명령의 기준은 공식 [Cloud Build submit 문서](https://docs.cloud.google.com/sdk/gcloud/reference/builds/submit)와
[Cloud Run jobs update 문서](https://docs.cloud.google.com/sdk/gcloud/reference/run/jobs/update)다.

증거 디렉터리: `spike-out/finding-fixes-20260914/`와 `spike-out/improvement-20260914/`.
